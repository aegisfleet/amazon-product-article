# システム設計ドキュメントポータル

本ディレクトリ（`docs/`）には、Amazon商品調査・記事自動生成プラットフォームのアーキテクチャ、データモデル、自動化パイプライン、およびフロントエンド設計に関する詳細仕様書が格納されている。

---

## ドキュメント一覧

### 1. アーキテクチャ & パイプライン

| ドキュメント | 概要 | 主な対象読者 / 参照タイミング |
|---|---|---|
| **[自動記事更新・生成システム](article-automation-system.md)** | 商品探索からJulesによるAI調査、PR検証・自動マージ、記事生成、Hugoデプロイ、定期リフレッシュに至る自律パイプライン全体の解説。 | システムアーキテクチャの把握、GitHub Actionsパイプライン改修時 |
| **[読者リクエスト処理システム](user-requests-system.md)** | Google Forms / GAS / GitHub Issue を連携させた読者からの商品調査リクエスト受付・自動投入フローの設計。 | リクエスト受付フォームやGASスクリプトの保守時 |

### 2. データ構造 & キャッシュ管理

| ドキュメント | 概要 | 主な対象読者 / 参照タイミング |
|---|---|---|
| **[カテゴリ管理・整理システム](category-management.md)** | 親カテゴリ命名規約（14文字以内）、Unicodeソート、Julesによる自動分類、正規化エンジン（`CategoryNormalizer`）の設計と修正手順。 | 新規カテゴリ追加、ジャンクカテゴリ除外、カテゴリ階層改修時 |
| **[ブランド管理システム](brand-management.md)** | `data/brandgroups.json` の仕様、単語境界（`\b`）によるブランド誤認防止策、ブランド自動抽出とページ生成の仕組み。 | ブランド定義追加・修正、ブランドページ生成時 |
| **[キャッシュ & データアーキテクチャ](cache-and-data-architecture.md)** | 本番キャッシュ（約56MB）と開発用ダミーキャッシュの多重マウント設計、TTL、ステータス遷移、リセットツールの解説。 | キャッシュトラブル調査、ローカル開発環境最適化時 |

### 3. UI/UX & フロントエンド

| ドキュメント | 概要 | 主な対象読者 / 参照タイミング |
|---|---|---|
| **[フロントエンド & UIアーキテクチャ](frontend-architecture.md)** | Hugo静的レンダリングと動的Vanilla JSの協調設計、カード部品（Hugo / JS）の二重管理・同期規約、検索ワーカー、比較機能の解説。 | 商品カード改修、動的フィルタ・検索・比較機能の拡張時 |
| **[サイトデザイン設計ガイドライン](../DESIGN.md)** | Material Design 3 (M3) トークン、タイポグラフィ、サーフェス階層、コントラスト比（WCAG 2.1 AA）規定。 | デザインシステム改修、カラー・コンポーネント追加時 |

## 運用ワークフロー手順書（実務ガイド）

実践的な調査・是正ステップについては、`.agent/workflows/` 配下のワークフロー手順書を参照のこと。

- **[カテゴリ管理ワークフロー](../.agent/workflows/category-management.md)**: カテゴリの調査・除外・修正およびキャッシュリセットの手順
- **[デッド商品棚卸しワークフロー](../.agent/workflows/prune-dead-products.md)**: 取扱終了商品の監査・削除手順
- **[スコア乖離是正ワークフロー](../.agent/workflows/resolve-score-discrepancy.md)**: バリエーション間での評価スコア乖離の調査・修正手順
- **[スペック調査ワークフロー](../.agent/workflows/spec-investigation.md)**: テクニカルスペックの調査・比較機能反映手順
- **[ワークフロー障害調査](../.agent/workflows/investigate-workflow-failure.md)**: GitHub Actions失敗時の原因調査手順
- **[ブラウザテスト手順](../.agent/workflows/browser-test.md)**: ブラウザ自動化ツールによる表示確認手順
