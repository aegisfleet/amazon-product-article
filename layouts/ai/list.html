power 1分で完了！公式MCPサーバーの接続方法（認証不要）

初回のみ以下のURLをAIクライアントに登録すると、以降は自然な会話だけで商品検索・スペック取得・複数商品の横並び比較ができるようになります。認証やAPIキーの取得は不要です（公開・読み取り専用、方式: MCP / Streamable HTTP）。

共通エンドポイント

MCP サーバー URL（コネクタ名の例: Amazon商品検索）

各AIツールのコネクタ・プラグイン設定画面で、以下のサーバーURLを貼り付けてください（名前は任意ですが、例として「Amazon商品検索」に統一しています）。

https://mcp.amazon-hikaku.com/mcp
ChatGPT

ChatGPT（Web版）での接続手順

  1. 左メニューの「プラグイン」を開く
  2. 「追加」（＋ボタン）→「カスタム MCP サーバーを追加」を選択
  3. 名前（例: Amazon商品検索）を入力し、「接続」のサーバー URL に https://mcp.amazon-hikaku.com/mcp を入力。認証は「認証なし」を選ぶ
  4. リスクに関する警告を確認し、「内容を理解したうえで続行」を選択
  5. 「プラグインとして作成」→ 検出されたツールを確認してインストール
  6. チャットで入力欄に @ と入力し、このプラグインを選んで質問する
Claude

Claude での接続手順

  1. 左メニューの「プラグイン」を開く
  2. 「追加」→「カスタムコネクタを追加」を選択
  3. 名前（例: Amazon商品検索）と MCP サーバー URL https://mcp.amazon-hikaku.com/mcp を入力
  4. 認証は「サインインなし」を選んで追加
  5. チャットで「+」→「コネクタ」から有効にして質問する
Grok

Grok での接続手順

  1. 設定 →「Connect Apps」を開き、下の方にある「Add a custom connector」を選ぶ
  2. 名前（例: Amazon商品検索）とサーバー URL https://mcp.amazon-hikaku.com/mcp を入力（ヘッダーは空で構いません）
  3. 「MCPを追加」を選択
Claude Code / Cursor 等

MCP 対応クライアント全般（JSON 設定）

Claude Code や Cursor など、設定ファイル（mcpServers）で管理するクライアントでは以下を追加してください。

{
  "mcpServers": {
    "amazon-hikaku": {
      "url": "https://mcp.amazon-hikaku.com/mcp"
    }
  }
}

chat 使い方の例（接続したAIへの質問例）

MCPサーバーを接続したあとは、URLや特別な命令文を貼る必要はありません。普段の言葉でAIに質問するだけで、該当するツールが自動で呼び出されます。

  • 「3万円以下で評価の高いワイヤレスイヤホンを探して」
  • 「Anker のモバイルバッテリーで一番おすすめはどれ？」
  • 「この2つの商品（ASIN: B0… と B0…）を比較して」
  • 「今セールで30%以上安くなっている商品を教えて」
  • 「ブラックフライデーのセールでおすすめはある？」（セールの種類は商品ごとのバッジで区別されます。開催前など該当がない時期は、その旨と現在開催中のセール種別一覧が返ります）
  • 「送料無料まであと少し。2,000円以下で良いものある？」
  • 「スコア90点以上の商品だけ見せて」

セール種別を指定した絞り込み

バッジ自動判別

セールの種類は商品ごとのバッジ（タイムセール／プライム会員限定セール／限定タイムセール／限定プライムセール／ブラックフライデー等）で区別されます。「ブラックフライデーのセールでおすすめは？」のように種別を指定でき、指定した種別が開催されていない時期は該当なしと現在開催中の種別一覧が返ります。

候補データに基づく聞き返しと出典リンク

対話型リサーチ

条件が曖昧な相談では、AIが候補データの実際の内訳（ブランド・カテゴリ・価格帯）をもとに予算や用途を聞き返すことがあります。回答には出典として当サイトの商品詳細レポートページへのリンクが添えられ、詳しいスペック表や価格推移（Keepa）をすぐ確認できます。

assistant 相談プロンプト（MCP Prompts・2種）

検索ツールのほかに、相談の進め方をAIに渡すテンプレート（MCP Prompts）を2件用意しています。MCP Prompts に対応したクライアントでは、コマンドやテンプレートとして選択できます（対応状況はクライアントによります）。

shopping_consultation

引数: topic

買い物相談用テンプレート。まず候補を調べ、予算・用途などが曖昧なら実際の選択肢で最大3点まで聞き返し、回答に合わせて再検索して比較と推奨まで進めます。引数 topic にテーマ（例: ワイヤレスイヤホン）を渡せます。

bargain_hunting

引数: occasion

セール・買い合わせ相談用テンプレート。セール商品と「あともう一品」候補を、割引率だけでなく独自スコアも見て絞り込みます。引数 occasion に用途を渡せます。

build MCPサーバーで使えるツール一覧（全8種）

AIアシスタントは以下の8つのツールを質問内容に応じて自動的に組み合わせて呼び出し、調査データを取得します。

ツール名 機能・できること
search_products キーワード／カテゴリ／ブランド／価格／スコアで商品を検索
get_product 1商品の詳細（スペック、在庫、調査日、スコアの採点根拠）
compare_products 2〜5商品の横並び比較
list_categories カテゴリ一覧（親→子の階層と件数）
list_brands ブランド検索（表記揺れにも対応）
get_deals セール中の商品（割引率順。低スコア品を避けるため既定でスコア70点以上。セール種別での絞り込みも可）
get_bargain 目標金額以下の「あともう一品」候補
get_recommendations スコア90点以上の高評価商品

content_paste 代替手段：MCPを接続できない環境向け コピペプロンプト集（llms.txt方式）

カスタムMCPサーバーの接続に対応していないプラン・アプリ環境では、以下のプロンプトをコピーして貼り付けることで、当サイトの標準案内ファイル（llms.txt）を経由して商品データを参照させることができます。「タブレット」などのキーワードはお好みの商品ジャンルに書き換えてご利用ください。

王道・定番

1. カテゴリ別の高評価商品を徹底調査・比較

指定したジャンル（タブレット、ワイヤレスイヤホン等）でスコア80点以上の高評価商品を抽出し、長所短所や比較表を生成させます。

https://www.amazon-hikaku.com/llms.txt を参照して、評価の高いおすすめの「タブレット」を調査・比較して（各商品の詳細レポートリンク付きで）。
コスパ重視

2. 予算上限つき！高コスパ商品の発掘

予算（例: 5,000円以内、10,000円以内など）を厳守しながら、スコア85点以上の高評価アイテムを厳選させます。

https://www.amazon-hikaku.com/llms.txt を参照して、「予算5,000円以内」で買える高コスパ商品を調査して（各商品の詳細レポートリンク付きで）。
買い合わせ

3. 「あともう一品」送料無料ライン調整アイテムの調査

Amazonの送料無料ライン（3,500円）まであと少しのときに役立つ、手頃で高評価な日用品・文具を提案させます。

https://www.amazon-hikaku.com/llms.txt を参照して、送料無料ラインに届く「2,000円以下」の手頃で高評価な日用品・文具を提案して（詳細レポートリンク付きで）。
セール特売

4. セール対象品からの掘り出し物ピックアップ

セール・割引中の商品データから、スコアが高い本当のお買い得品をAIに選ばせます。

https://www.amazon-hikaku.com/llms.txt を参照して、現在セール対象となっている注目の高評価商品をピックアップして（詳細レポートリンク付きで）。
スペック対決

5. 迷っている2製品のガチンコ徹底比較

購入を迷っている2つの製品（ASINや製品名）を指定し、詳細なスペック対比や長所短所をAIに白黒つけさせます。

https://www.amazon-hikaku.com/llms.txt を参照して、「[商品A]」と「[商品B]」のスペック、独自スコア、長所短所を徹底比較して（両方の詳細レポートリンク付きで）。

psychology 各AIツールでの使い分け・おすすめ機能

ChatGPT・Claude・Grokでは公式MCPサーバー接続でダイレクトに検索でき、MCP未接続の環境でもllms.txt経由で調査データを活用できます。

ChatGPT (OpenAI)

カスタムMCPプラグイン対応

「プラグイン」からカスタムMCPサーバーを追加し、チャット入力欄で @Amazon商品検索 を選ぶだけで、大きなJSONファイルを読み込ませることなく必要な商品だけを高速に検索・比較できます。

Claude (Anthropic)

カスタムコネクタ / Artifacts

「カスタムコネクタ」にMCPサーバーを登録して対話的に商品検索・採点根拠の参照が可能です。また、llms.txt 方式や検索結果の表示時に「HTML（Artifacts）形式で商品カードUIを出力して」と指示すると、写真付きの商品カードをプレビュー表示できます。

Grok (xAI)

Connect Apps (MCP対応)

設定の「Connect Apps」→「Add a custom connector」からMCPサーバーを直接接続できます。Grok上で当サイトの独自スコアやセール情報、採点根拠を呼び出しながらスピーディーに比較検討できます。

Muse (Meta)

llms.txt 方式で利用

Metaの自律型パーソナルAI「Muse」では（MCP接続は未確認）、Webブラウジング機能を活用して上記の「llms.txt コピペプロンプト集」を貼り付けることで、条件に合致する商品を自律的に調査・比較させることができます。

info

llms.txt 方式（URL直接参照）での Google Gemini のご利用について: Geminiのチャット画面で外部URL（llms.txt）を直接読み取らせる方式は、Google検索キャッシュ経由の仕様により取得エラーとなるため非推奨です。llms.txt のコピペプロンプトを使う場合は ChatGPT、Grok、Claude、または Muse をご利用ください（一番確実で高速な方法は上記の MCPサーバー接続 です）。

データの更新頻度・価格・独自スコアに関するご注意:
  • MCPサーバーのデータは当サイトの調査結果そのもので、サーバー側で1時間ごとに最新の公開データへ自動更新されます（読み取り専用）。
  • 返される価格は各商品の「調査時点の参考価格」です。リアルタイムの最新価格や在庫状況、タイムセール状況は、回答に添えられる当サイトの商品詳細レポートページにて必ずご確認ください。
  • 独自スコア（0〜100点）は当サイト独自の客観採点（基本点＋加点・減点）であり、各商品の採点根拠（score_rationale）もMCP経由で参照できます。
