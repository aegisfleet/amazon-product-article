chat MCPサーバーでできること・質問例

MCPサーバーを接続しておくと、買い物の相談をしたときにAIが当サイトの調査データを直接検索し、独自スコア（0〜100点）・価格・スペック・長所と短所・採点根拠にもとづいて候補の提案から横並び比較まで行います。

質問例

接続したAIに、たとえばこう聞けます

  • 「3万円以下で評価の高いワイヤレスイヤホンを探して」
  • 「ソニーのノイキャンイヤホンでおすすめは？」（ブランドのカタカナ表記や略語でも探せます）
  • 「Anker のモバイルバッテリーで一番おすすめはどれ？」
  • 「この2つの商品（ASIN: B0… と B0…）を比較して」
  • 「今セールで30%以上安くなっている商品を教えて」
  • 「ブラックフライデーのセールでおすすめはある？」（セールの種類は商品ごとのバッジで区別されます。開催前など該当がない時期は、その旨と現在開催中のセールが返ります）
  • 「送料無料まであと少し。2,000円以下で良いものある？」
  • 「スコア90点以上の商品だけ見せて」

条件検索と2〜5商品の横並び比較

スコア・採点根拠つき

キーワード・カテゴリ・ブランド・予算・スコアで候補を絞り込み、気になる複数商品のスペックや長所・短所、なぜその点数になったかの採点根拠（score_rationale）まで横並びで比較できます。

セール種別の指定・「あともう一品」検索

バッジ自動判別

タイムセール／プライム会員限定セール／ブラックフライデーなどセールの種類を指定した掘り出し物探しや、送料無料ライン調整に便利な「2,000円以下の高評価アイテム」の抽出も一瞬で行えます。

曖昧な相談への聞き返しサポート

対話型リサーチ

条件が曖昧な相談では、AIが候補データの実際の内訳（ブランド・カテゴリ・価格帯）をもとに予算や用途の絞り込みを聞き返すことがあります。そのまま答えると条件に合わせて候補を調べ直してくれます。

出典として商品詳細レポートURLを添付

詳細ページ直行

AIは出典として当サイト（amazon-hikaku.com）の商品詳細ページへのリンクを添えて回答します。詳しいスペック表や価格推移（Keepa）、最新の価格・在庫状況はリンク先ですぐに確認できます。

power MCPサーバーの接続方法（設定手順）

お使いのAIツールに以下のサーバーURLを登録するだけで準備完了です（認証不要・公開・読み取り専用、方式: MCP / Streamable HTTP）。

共通エンドポイント

MCP サーバー URL（コネクタ名の例: Amazon商品検索）

各AIツールの設定画面で以下のURLを入力してください（名前は任意ですが、例として「Amazon商品検索」に統一しています）。

https://mcp.amazon-hikaku.com/mcp
ChatGPT Gemini Claude Grok Muse JSON設定 (Claude Code / Cursor等)
ChatGPT

ChatGPT（Web版）

  1. 左メニューの「プラグイン」を開く
  2. 「追加」（＋ボタン）→「カスタム MCP サーバーを追加」
  3. 名前（例: Amazon商品検索）を入力し、「接続」のサーバー URL に https://mcp.amazon-hikaku.com/mcp を入力。認証は「認証なし」を選ぶ
  4. リスクに関する警告を確認し、「内容を理解したうえで続行」を選択
  5. 「プラグインとして作成」→ 検出されたツールを確認してインストール
  6. チャットで入力欄に @ と入力し、このプラグインを選んで質問する
Gemini

Gemini

  1. 左メニューの「カスタマイズ」を開き、「連携サービス」タブで「カスタム」を選ぶ

  3. カスタム接続済みアプリについての注意を確認して接続を完了する（認証は不要です）

verified
データと安全性について:
  • データは当サイト（amazon-hikaku.com）の調査結果そのもので、サーバー側で1時間ごとに最新の公開データへ更新されます。
  • 価格は各商品の「データ更新時点の参考価格」です（価格は調査とは別に更新されるため、調査日の価格とは異なる場合があります）。最新の価格や在庫状況はリンク先の商品詳細ページでご確認ください。
  • スコアはサイト独自の採点（基本点＋加点・減点）で、各商品の score_rationale に採点根拠が入っています。
  • 完全読み取り専用・オープンソース公開: 書き込み機能はなく、アカウント情報や会話履歴も保存しません。サーバーのソースコードは GitHub（aegisfleet/amazon-hikaku-mcp） で公開しています。
build 技術情報：搭載ツール（9種）・相談プロンプト（2種）・セキュリティ設計とソースコード 普段はAIが自動選択するため意識不要です（クリックで詳細）

MCP サーバーには以下の9つのツールと2つの相談用テンプレート（MCP Prompts）が搭載されており、質問内容に応じて AI が自動的に呼び出します。

ツール名 内容
search_products キーワード／カテゴリ／ブランド／価格／スコアで商品を検索。ブランドの日英表記ゆれ（ソニー／Sony 等）や略語・同義語（ノイキャン、USB-C／Type-C 等）も自動で吸収
get_product 1商品の詳細（スペック、在庫、調査日、スコアの採点根拠）
compare_products 2〜5商品の横並び比較（最安・最高スコア・価格差などの要約と、長所・短所リストつき）
find_similar_products 指定商品と同カテゴリの代替候補（在庫切れ・予算超過のときに）
list_categories カテゴリ一覧（親→子の階層と件数）
list_brands ブランド検索（表記揺れにも対応）
get_deals セール中の商品（既定はスコアと割引率のバランス順。低スコア品を避けるため既定でスコア70点以上。セール種別での絞り込みも可）
get_bargain 目標金額以下の「あともう一品」候補（下限金額の指定も可）
get_recommendations スコア90点以上の高評価商品

MCP Prompt: shopping_consultation

引数: topic

買い物相談用。まず候補を調べ、予算・用途などが曖昧なら実際の選択肢で最大3点まで聞き返し、回答に合わせて再検索して比較と推奨まで進めます。引数 topic にテーマ（例: ワイヤレスイヤホン）を渡せます（※MCP Prompts 対応クライアントで選択可）。

MCP Prompt: bargain_hunting

引数: occasion

セール・買い合わせ相談用。セール商品と「あと一品」候補を、割引率だけでなくスコアも見て絞り込みます。引数 occasion に用途を渡せます（※MCP Prompts 対応クライアントで選択可）。

透明性と安全策

ソースコード公開とセキュリティ設計（MIT License）

リモート MCP サーバーをお使いの AI アシスタントに安心して接続いただけるよう、サーバー実装・プロンプト定義・テストコード一式を GitHub で完全公開し、以下の安全策を講じています。

  • オープンソース公開（GitHub）: https://github.com/aegisfleet/amazon-hikaku-mcp（MIT License / SECURITY.md）にて全コードとセキュリティポリシーを公開しています。
  • 完全読み取り専用（副作用なし）: 公開している全9ツールに MCP 標準アノテーション ToolAnnotations(readOnlyHint=True, destructiveHint=False, idempotentHint=True) を設定しており、外部データの書き換えや注文・決済などの操作は一切行いません。
  • ステートレス設計・個人情報の非保持: Streamable HTTP のステートレスモード（stateless_http=True）で稼働し、API キー・OAuth トークン・アカウント情報・会話セッション履歴を保持しません。
  • データソースの限定: サーバーが参照するのは当サイト（amazon-hikaku.com）で公開配信している調査 JSON のみ（1時間キャッシュ）であり、任意の外部 URL へアクセスする機能（SSRF リスク）は持ちません。
  • 通信保護・過負荷防止ガード: リクエストサイズ上限（64KB、ヘッダー検査およびストリーム実測）と IP 単位のレート制限（240 req/min）、各種セキュリティヘッダー（X-Content-Type-Options: nosniff、Cache-Control: no-store 等）を適用しています。
  • コンテナとサプライチェーン保護: uv.lock による依存パッケージの固定ビルド、非特権ユーザー（non-root）でのコンテナ実行、GitHub Actions（pip-audit）および Dependabot による継続的な脆弱性スキャンを実施しています。
